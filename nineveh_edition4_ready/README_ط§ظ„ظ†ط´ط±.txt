تشغيل الموقع أونلاين
====================
1) محلياً:  pip install -r requirements.txt  ثم  python server.py
   - يطبع رابط لوحة الأدمن مع كلمة السر (وتُحفظ في admin_key.txt).
2) على استضافة (Render / Railway / VPS)  <-- هذا ما يجعل الطلبات تصلك من أي مكان:
   - أمر التشغيل: python server.py
   - متغيرات البيئة:
       ADMIN_KEY = كلمة سر طويلة من اختيارك
       BASE_URL  = رابط موقعك مثل https://yoursite.com
   - فعّل Persistent Disk لحفظ db.json و pdfs/ وإلا تضيع الحجوزات عند إعادة التشغيل.
3) لوحة الأدمن:  https://yoursite.com/admin?key=كلمة_السر
   - تعمل على الهاتف والكمبيوتر والماك وأي جهاز، وتُحدَّث لحظياً (بث مباشر SSE + فحص كل 5 ثوانٍ كاحتياط).
   - عند وصول حجز جديد: صوت + اهتزاز + إشعار (اضغط "تفعيل إشعارات الجهاز" مرة واحدة).
   - أزرار: موافقة / رفض / واتساب / PDF.
   - ملاحظة: الإشعارات تظهر والصفحة مفتوحة (حتى لو في الخلفية). أضفها لشاشة الهاتف الرئيسية للوصول السريع.
